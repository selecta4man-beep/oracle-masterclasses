# 16 Masterclasses interactives — Procédure d'upload

Les 16 HTML `MC01.html → MC16.html` sont interactifs (navigation flèches, sections, quiz, score).
L'`index.html` est la page catalogue qui liste les 16, avec un lien vers chacune.

## OPTION 1 — GitHub Pages (recommandé)

1. Va sur https://github.com → connecte-toi
2. "+" en haut à droite → "New repository"
3. Nom : `masterclasses` · coche "Public" · NE PAS cocher "Add a README"
4. "uploading an existing file" → glisse-dépose les 17 fichiers (ou le dossier entier)
5. "Commit changes"
6. Onglet "Settings" → menu gauche "Pages"
7. "Build and deployment" → Source = "Deploy from a branch", Branch = "main" + "/ (root)" → "Save"
8. Attends 1 min → URL affichée : `https://<ton-pseudo>.github.io/masterclasses/`

## Après l'upload

Donne-moi l'URL. Je crée 17 activités URL dans Digiforma (ressource 3139698) :
- 1 vers l'index catalogue
- 16 vers chaque masterclass directement

Les bénéficiaires auront une expérience équivalente à Genially :
- Clic sur une masterclass → ouverture plein écran
- Navigation slide par slide avec flèches
- Quiz à la fin avec correction immédiate et score
